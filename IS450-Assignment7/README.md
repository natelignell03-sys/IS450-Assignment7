## Project Description
This Python program tracks the final score of a basketball game. The user enters two team names and their scores. The program displays the final scores, identifies the winning team, and calculates the margin of victory. It also handles tied games.

## Input
- The names of two basketball teams.
- A nonnegative whole-number score for each team.

## Output
- Both teams' final scores.
- The winning team's name and margin of victory, or a tie message.
- Helpful prompts when an invalid score is entered.

## Python Concepts Used
- **Variables** store team names and scores.
- **Input** gathers information from the user.
- **Functions** organize the program into reusable sections.
- **Loops** allow the user to retry invalid scores.
- **Conditionals** determine which team won or whether the game was tied.

## How to Run
1. Install Python 3 and open the cloned `IS450-Assignment7` repository folder in Visual Studio Code.
2. Open the terminal in VS Code (`Terminal` > `New Terminal`).
3. Run `python myProgram.py` (or `python3 myProgram.py` if needed).
4. Enter the two team names and scores when prompted.
5. Read the final score and winner in the terminal.
